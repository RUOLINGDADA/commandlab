## 第一次运行容器：从概念到可复现证据

本节围绕 **用短命令和长命令观察容器前台与后台状态** 设计。请把练习当作一次真实开发或值班任务：先确认上下文，再执行最小操作，最后用验证命令证明结果。浏览器不会执行 Docker 命令，代码块只会被复制到你的本机终端。

### 练习协议

先完成题目，再展开答案。所有资源统一使用 `commandlab-` 前缀；涉及删除、挂载、网络、端口、权限或资源限制时，先阅读步骤中的影响范围。错误出现时不要立即重试，保留错误文本并按照“对象—状态—原因—恢复”顺序排查。

### 输出判断

Docker 的 ID、时间、镜像摘要和平台架构会因本机变化。本节验收关注关键字段：对象是否存在、状态是否正确、数据是否保留、命令是否返回预期退出码，以及输出是否包含目标名称或健康状态。

### 课后复盘

完成后回答：这条命令操作的是镜像、容器、卷、网络还是构建缓存？它是否改变了宿主机文件？再次执行会复用什么、重新创建什么？把答案写进本地课程笔记，下一节会继续使用这些判断。
