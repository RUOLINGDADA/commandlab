## 场景背景

为批处理容器设置 CPU、内存和日志上限，观察资源配置与退出状态，避免单个任务拖垮主机。

## 核心概念

本节围绕“CPU、内存与日志管理”建立对象边界。先辨认命令操作的是镜像、容器、卷、网络、构建上下文还是 Compose 项目，再判断哪些状态由 Engine 持久保存，哪些只属于容器主进程。

## Docker 执行流程

CLI 解析本节参数并把请求发送到当前 Docker context。Engine 检查 busybox:1.36 及依赖对象，按需拉取或复用镜像层，随后创建、更新或读取 commandlab- 资源。验证阶段只读取名称、状态、退出码、挂载、端口、健康状态或资源限制等稳定字段。

## 课后复盘

完成后回答：主任务创建或改变了什么？变体复用了什么？宿主机端口、路径、网络或数据是否受到影响？再次执行前需要保留哪些证据，清理时为什么不能使用全局 prune？
