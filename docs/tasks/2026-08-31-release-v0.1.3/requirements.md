# CommandLab v0.1.3 发布

## 已确认目标

- 将当前已完成的交互式 Git 工作台、终端紧凑布局、可见 `>` 操作入口和远端同步功能发布为 `v0.1.3`。
- 将代码合并到受保护的 `main`，创建 GitHub Release，并触发 GitHub Pages 部署。

## 范围

- 根项目与 5 个工作区包版本统一为 `0.1.3`。
- 更新发布说明、项目状态、任务档案和交接信息。
- 执行格式、Lint、类型、测试、内容校验、生产构建和 Pages 静态导出验证。

## 不包含范围

- 不删除既有 Release、标签或远程分支。
- 不修改 Docker Desktop 本机环境，不新增后端、账号或数据库。

## 验收标准

- `main` 包含本轮功能提交和 `v0.1.3` 版本提交，工作区干净。
- GitHub Release 页面存在 `v0.1.3`，目标为最新 `main`。
- Release 与 Pages 工作流成功，线上首页和 `/terminal/` 可返回 HTTP 200。
- 本地工程检查全部通过，发布文档准确记录提交、工作流和剩余风险。
