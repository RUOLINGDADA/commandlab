# 决策记录

## 2026-08-31

- 远端文件使用 schema 校验的 `remoteFiles` 数组，复用文件的 `path/version` 语义，状态固定为 `clean`；这样 pull 可以确定性地比较并合并文件。
- `git remote touch <path>` 是浏览器仿真器的明确扩展命令，仍使用 Git 的 remote 命名空间，避免伪造宿主机文件操作。
- `>` 入口使用普通按钮而不是依赖右键事件；右键处理可以保留作桌面辅助，但所有功能必须从可见入口可达。
- pull 同步远端文件后保留远端提交节点，并在本地工作树中写入 clean 文件；若本地同路径版本较旧，则更新版本而不覆盖本地未提交改动。
