# Bug 记录

## 2026-08-31：浏览器右键入口不可用

- 现象：在当前浏览器环境中右键事件无法稳定触发工作区动作菜单。
- 根因：交互依赖 `contextmenu` 事件，浏览器/桌面容器可能拦截或不转发右键。
- 修复：为所有工作区对象增加可见 `>` 操作按钮，动作菜单改由 click 触发；右键处理仅作为桌面辅助入口。
- 回归测试：已通过工作区入口存在性、菜单动作回放和桌面/390px 点击验收。

## 2026-08-31：远端文件无法通过 pull 进入工作区

- 现象：仿真远端只有 ref 字符串，`git pull` 不会新增或更新工作区文件。
- 根因：状态 schema 和 reducer 缺少远端文件快照及合并逻辑。
- 修复：加入受 schema 校验的 `remoteFiles`，实现 `git remote touch/files`、远端提交和 pull 文件同步；本地同路径未提交变更会保留并报告冲突。
- 回归测试：已通过远端创建、pull 新文件、版本更新和未提交文件保护测试。
