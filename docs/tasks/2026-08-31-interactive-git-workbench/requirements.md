# 交互式 Git 仿真终端与工作区

## 已确认目标

- 新增浏览器内运行的 Git 仿真终端和可操作工作区。
- 终端可输入命令并将结果同步到文件、暂存区、提交图、分支、HEAD、远端和 stash 视图。
- 视觉语言沿用 CommandLab；工作区参考 zcode 首页的 IDE 布局，命令体验参考 learnGitBranching 的即时反馈。

## 范围

- 覆盖现有 Git 百科注册的全部命令及常用只读/变更参数，使用隔离的内存状态，不执行宿主机命令。
- `/terminal` 提供完整工作台；首页工作区提供可进入仿真器的真实入口。
- 支持终端历史、清屏、帮助、重置、点击文件/分支/提交/远端对象生成只读命令。
- 不实现公网后端、真实文件写入或 Docker 仿真。

## 验收标准

- 输入 `git init`、`git add`、`git commit`、`git branch`、`git switch`、`git merge`、`git log`、`git status` 等命令后，终端输出和工作区状态同步变化；全部现有 Git 命令都有明确输出或状态反馈。
- 无效命令、缺失引用、空暂存区等错误会显示可理解信息，且执行前后的状态、提交图和历史不被破坏。
- 点击文件、分支、提交、stash 或远端引用会更新选中状态并在终端回显对应只读命令；重置会恢复固定隔离仓库。
- 桌面与 390px 移动端可点击、可输入、无整体横向溢出；刷新页面回到初始会话。
- `pnpm test`、`pnpm typecheck`、`pnpm lint`、`pnpm format:check` 和 `pnpm build` 通过。
