# Docker 课程质量重构与工具百科需求

## 已确认目标

- Docker 24 节课程题目只描述任务，不在题目区域展示命令。
- 参考答案、验证、清理和排错信息必须具体、可复制、可解释。
- 互动题按主题设计，避免重复模板。
- 通用练习协议只在 Docker 课程路径首页展示一次。
- 课程时长按步骤量重新标注，控制在 10–40 分钟。
- 新增 Git、Docker 工具百科，使用总入口加工具子页。

## 范围

修改 Docker Schema、24 节 Docker MDX、实操组件、课程导航、百科数据与页面、测试和项目文档。Git 课程仅做回归验证，不重写内容；不新增后端、在线沙箱或 Release。

## 验收标准

- Docker 24 节全部通过 Schema 和跨文件校验。
- 每个步骤的题目不包含命令语法，命令仅在答案、验证、清理或平台指引中出现。
- 每个步骤具备具体答案、预期、验证、清理、坑点和恢复信息。
- 24 道互动题题型与内容不重复。
- `/reference/`、`/reference/git/`、`/reference/docker/` 可静态导出并支持搜索。
- 完整 lint、类型、内容、单元测试、构建和 Pages 导出校验通过。
