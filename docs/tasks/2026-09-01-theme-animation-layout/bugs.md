# 缺陷记录

## BUG-20260901-01

- 现象：主题筛选文字挤在一起，项目间没有清晰分隔。
- 复现：打开任一 `/reference/<tool>/`，观察筛选项，缩放到 390px。
- 根因：筛选按钮继承全局样式但筛选行没有专属间距/换行约束。
- 修复：筛选器使用独立按钮边界、6px `gap` 和窄屏换行。
- 回归测试：`tests/theme-animation-layout.test.ts`；390px 浏览器检查。
- 状态：已解决。

## BUG-20260901-02

- 现象：点击“观看动画”后主题突然变化。
- 复现：切换浅色主题，再从百科卡片进入动画详情。
- 根因：入口使用原生 `<a>` 触发整页导航，服务端默认主题先覆盖当前 DOM 状态。
- 修复：动画入口改用 Next `Link`；根布局在 `beforeInteractive` 阶段恢复本地主题；主题按钮使用稳定的订阅快照避免 hydration 不一致。
- 回归测试：`tests/theme-animation-layout.test.ts`；浅色主题点击动画并整页加载后仍为浅色。
- 状态：已解决。

## BUG-20260901-03

- 现象：课程中的嵌入动画被遮挡，无法展示完整节目。
- 复现：打开课程详情，在窄屏或多命令课程中查看动画舞台。
- 根因：嵌入卡片沿用完整动画页的 Git/Docker 多列最小轨道，窄卡片中子面板横向穿出并遮挡相邻内容；Git 命令栏的固定列也会撑宽舞台。
- 修复：嵌入模式将 Git/Docker 专属网格改为单列，Git 上下文和命令栏使用可收缩轨道；卡片隔离溢出，提交图保留自身滚动区域。
- 回归测试：`tests/theme-animation-layout.test.ts`；Git/Docker 课程桌面与 390px 检查卡片边界、页面宽度和相邻卡片不重叠。
- 状态：已解决。

### 回归加固

- 复测发现嵌入舞台使用 `overflow: hidden` 时，极端窄卡片中的超宽专属内容仍可能被裁切。
- 已改为舞台和画布 `overflow: auto`，并限制 `max-width: 100%`；内容超宽时可在卡片内部完整查看。
- 回归证据：390px Git/Docker 课程页面卡片边界无溢出，舞台计算样式为 `overflow: auto`。
