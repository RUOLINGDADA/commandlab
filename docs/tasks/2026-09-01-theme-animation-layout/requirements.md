# 主题与动画布局修复

## 已确认目标（2026-09-01）

1. 主题筛选文字有清晰的间距/分隔，在桌面和 390px 宽度下不互相挤压。
2. 从百科点击“观看动画”后保持当前主题，不因整页导航或初始化闪变主题。
3. 课程详情页内嵌动画完整展示，不被固定尺寸、溢出或层叠遮挡；播放控制仍可用。

## 范围

- 百科筛选器与动画入口组件、主题初始化逻辑、课程动画嵌入/专属舞台布局及相关样式。
- 增加覆盖导航入口与布局约束的回归检查，并执行受影响范围的工程验证。

## 不包含

- 不改变课程 Schema、百科内容模型、动画语义、真实 Git/Docker 执行或发布流程。

## 验收标准

- 筛选项之间可见分隔且能在 390px 宽度换行/滚动，不发生文字重叠。
- 已选择浅色或深色主题时，点击动画入口后主题保持不变，且无明显整页主题闪变。
- 课程动画在桌面和 390px 宽度都能看到完整舞台，内容不被父容器裁切，控制按钮可操作。
- 相关测试、格式、Lint、TypeScript 与生产构建通过。
