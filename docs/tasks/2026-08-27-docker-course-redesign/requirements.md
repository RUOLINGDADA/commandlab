# Docker 课程深度重设计需求

## 目标

重做 Docker 24 节课程，使零基础学习者可以围绕真实场景完成可复制、可验证、可清理的本机练习。

## 范围

- 仅修改 Docker 24 节、课程 Schema、课程详情页和练习交互组件。
- 保留 Docker 既有课程编号、slug、主题顺序和 Git 课程现状。
- 支持 Linux、Windows WSL2、macOS；镜像按案例选择，优先官方或可信第三方镜像。
- 不创建在线 Docker 沙箱，不增加后端、登录或云端执行能力。

## 验收标准

- 24 节课程全部通过新 Schema 与内部链接校验。
- 每节至少一个真实场景；高级和精通课程至少两个场景。
- 每个实操步骤都有题目、答案、关键预期结果、验证命令、清理命令、提示和衍生练习。
- 答案默认折叠，步骤可以独立标记完成并持久化到 IndexedDB。
- 所有危险操作使用 `commandlab-` 资源前缀并提示影响范围。
- 静态构建、类型、Lint、单元测试和导出检查通过。
