# 全量命令百科与首页动效重构

## 目标

- 建立覆盖 Git 与 Docker 常用命令族的百科索引，展示命令语法、参数解析、对象、风险、示例、错误与关联课程。
- 首页视觉明显升级为产品化文档工具入口：强首屏、任务式工作区预览、层级分明的模块和可感知但不妨碍阅读的动效。
- 百科支持按工具、命令搜索和参数阅读，方便命令行零基础用户从“这条命令做什么”开始理解。

## 范围

- `content/reference/` 内容与参数字段。
- `apps/web` 首页、百科列表和相关样式/动效。
- 内容 schema、测试和项目交接文档。

## 验收标准

- Git 与 Docker 百科均提供命令目录，命令条目含完整语法、参数逐项解释和至少一个可复制示例。
- 首页在桌面和移动端有首屏入场、卡片悬浮、滚动显现和终端光标等动效；`prefers-reduced-motion` 下自动减弱。
- 百科页面可搜索命令/参数，搜索无结果时有清晰空状态；页面无横向溢出。
- 内容校验、类型检查、lint、测试、格式检查、生产构建和浏览器验收通过。
