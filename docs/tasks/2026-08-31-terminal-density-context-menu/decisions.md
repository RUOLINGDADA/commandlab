# 决策记录

## 2026-08-31

- 复用 `executeInteractiveGitCommand` 作为所有右键动作和候选命令的唯一执行入口，避免出现第二套状态逻辑。
- 候选提示使用现有 `interactiveGitCommands` 加少量常用参数模板生成；提示只影响输入框，不自动执行命令。
- 菜单定位以工作台容器为边界并在视口内钳制，确保窄屏和底部列表不会溢出。
- 终端输出使用固定的工作台行轨道和 `overflow-y: auto`，移动端也保留内部滚动而不是让页面无限增长。
- 分支右键只为非当前分支展示删除动作，当前分支保留切换/历史操作，降低误操作风险。
