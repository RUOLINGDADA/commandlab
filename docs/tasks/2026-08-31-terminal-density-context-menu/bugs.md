# Bug 记录

## 2026-08-31：终端输出撑长页面

- 现象：输出行持续累积时，页面高度随内容增加，终端缺少明确的内部滚动边界。
- 复现：在 `/terminal/` 连续执行多条 `git help`、`git log` 或错误命令。
- 根因：终端面板只有最小高度，输出区域虽可滚动但没有稳定的可视高度和紧凑行规则。
- 修复：工作台网格使用明确高度，终端输出设置 `overflow-y: auto`、稳定滚动槽和紧凑行距；移动端使用独立高度。
- 回归测试：连续 9 条 `git help` 后输出 `scrollHeight` 增长而页面 `scrollHeight` 不变，390px 下输出仍可滚动。
- 状态：已修复。

## 2026-08-31：工作区缺少上下文菜单与命令提示

- 现象：工作区对象只能左键触发固定动作，输入命令没有候选提示。
- 复现：右键文件或分支；在终端输入 `git st`。
- 根因：组件未注册 `contextmenu` 事件，也没有输入前缀到候选命令的映射。
- 修复：工作区目标统一注册右键事件，使用 `role=menu/listbox` 展示动作和候选，并通过仿真执行器回放。
- 回归测试：Vitest 覆盖前缀过滤和动作映射；浏览器覆盖文件、提交、分支、远端菜单及 Escape/动作关闭。
- 状态：已修复。
