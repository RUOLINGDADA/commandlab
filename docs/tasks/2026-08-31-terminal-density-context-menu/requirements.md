# 终端紧凑布局、右键菜单与命令提示

## 已确认目标

- 终端输出固定在工作台区域内，内容过多时由终端自身滚动，不再持续撑长页面。
- 终端输出采用更紧凑的 Git 工具风格：小行距、连续命令提示符、较少段落间距。
- 工作区文件、分支、提交、远端和 stash 行支持右键上下文菜单，并将菜单动作映射为仿真 Git 命令。
- 终端输入根据当前文本提供 Git 命令提示，可用上下键、Tab 或点击选择。

## 范围

- 仅修改浏览器内存中的交互式 Git 工作台、样式、相关测试和项目记录。
- 右键菜单动作继续通过现有 `executeInteractiveGitCommand` 执行，不访问宿主机文件系统、Shell 或真实 Git。
- 保持现有 CommandLab 视觉语言、桌面三栏布局和移动端纵向布局。

## 验收标准

- 输入足够多的命令后，`/terminal/` 页面整体高度保持稳定，终端输出区域可独立滚动并自动定位到最新输出；390px 视口同样成立。
- 每条终端命令和输出以紧凑行距连续显示，不出现由默认段落边距造成的大块空白。
- 右键文件、分支、提交、远端或 stash 显示不越出工作台的菜单；点击菜单动作会回显对应命令并更新状态，点击外部或 Escape 会关闭菜单。
- 输入 `git `、`git st`、`git co` 等前缀出现匹配候选；上下键移动候选，Tab 或点击候选填入命令，Enter 仍可执行原输入。
- 右键和补全交互不会破坏已有状态、历史、清屏、重置和错误回滚行为。
- `pnpm test`、`pnpm typecheck`、`pnpm lint`、`pnpm format:check`、`pnpm validate:content` 和 `pnpm build` 通过。
