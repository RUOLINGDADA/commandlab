# 新手教程走查与优化

## 已确认目标

以第一次接触电脑和 Docker 的学习者视角，实际走完一个教程，找出不合适、难理解或无法继续的环节并优化。

## 已复现范围

- Docker 学习路径与第一节《Docker 安装检查与工作原理》。
- 课程首页、嵌入动画、分级提示、参考答案、互动题、步骤完成和在线终端入口。

## 验收标准

- 课程首次进入时不会让多个嵌入动画同时自动播放，学习者能明确知道当前要先做什么。
- 课程步骤提供清晰的浏览器内练习入口，同时保留复制到本机的真实 Docker 命令路径。
- 动画的准备阶段和控制区对新手有可见的观察目标，不依赖先理解 Engine、CLI、context 等术语。
- 完整走完第一节的提示、练习、互动题和完成状态后，反馈明确且下一节入口可见。
- 390px 与桌面视口无横向溢出，相关测试和工程校验通过。
