# 主页在线终端工作台

## 已确认目标

- 将主页当前的紧凑终端预览直接替换为可输入命令、可点击工作区对象的完整 Git 仿真终端。
- 参考 ZCode 主页的工作台信息架构：首屏突出任务入口，工作区作为主要操作面，使用侧栏、主内容区和终端形成持续操作流。
- 保持 CommandLab 现有视觉语言、中文内容、内存隔离和 Git 仿真边界。

## 范围

- 重排主页首屏与在线工作区布局。
- 主页接入 `InteractiveGitWorkbench` 完整模式；终端独立页面与课程页的已有入口继续可用。
- 完成桌面和窄屏浏览器验收，确保命令输入、快捷动作、对象点击和终端滚动仍可用。

## 不包含

- 不接入宿主机真实 Shell、Git、账号或远端服务。
- 不改变课程内容模型、Git 状态机语义和在线终端页面的核心交互。

## 验收标准

- 主页不再渲染 `interactive-git-compact`，首屏直接显示完整 `interactive-git-workbench`。
- 用户可在主页终端输入并执行 `git status`、`git add .`、`git log --oneline` 等命令，状态面板同步更新。
- 桌面布局保持侧栏、提交图和终端同时可见；窄屏布局不产生整体横向溢出，终端仍有独立滚动区域。
- 工程格式、Lint、TypeScript、测试、内容校验、生产构建和静态导出通过。
