# 需求确认

## 目标

自行通过浏览器全面验证 Git 与 Docker 两个在线终端的功能、交互、状态同步和信息展示，修复现有及审计中发现的潜在问题。

## 验收范围

- Git/Docker 工作台模式切换与 URL 参数入口。
- 命令输入、执行、历史、清屏、重置、帮助、补全、Tab/方向键选择。
- 成功命令的状态变化、失败命令的原状态保护和错误提示。
- Git 文件、分支、提交、远端、stash、远端文件与 pull 同步动作。
- Docker 容器、镜像、网络、卷、端口、Compose、日志、健康状态、资源指标和清理动作。
- 桌面与 390px 视口的布局、滚动、文本可读性和控件可操作性。

不包含发布、远端仓库写入、宿主机 Git/Docker 操作和无关页面重构。

## 验收标准

- 两个终端的所有可见入口均可触发正确动作，状态面板与终端输出一致。
- 错误命令显示明确原因，且不会修改工作台状态。
- 重置、清屏、模式切换和 URL 入口行为稳定，不丢失或错误复用另一模式的状态。
- 关键对象信息不截断、不重叠，移动端无横向溢出。
- 每个发现的缺陷都有回归测试或可重复的浏览器证据。
- pnpm validate:content、pnpm test、pnpm typecheck、pnpm lint、pnpm format:check、pnpm build 全部通过。
