# Docker 指南风格课程体系重构需求

## 目标

参考 Docker 中文指南的循序渐进教学方式，原创重写 Docker 24 节课程，重新编排主题与 slug。每节包含一个主任务和一个变体任务，并完整解释命令参数、Docker 执行流程、预期结果、验证、故障恢复和精确清理。

## 范围

- 重写 Docker Schema、24 节课程、互动题和百科关联。
- 更新静态路由测试、导出校验、项目状态与交接文档。
- Git 课程保持不变。
- 不保留旧 Docker 页面，不创建后端、在线沙箱或新 Release。

## 验收标准

- 24 节 Docker 课程使用新目录和新 slug，每级六节。
- 每节恰好一个主任务和一个变体任务，题目不泄露命令。
- 答案包含参数说明、执行流程、预期状态、只读验证和定向清理。
- 使用现代 Docker 命令和官方镜像，资源统一使用 `commandlab-` 前缀。
- 内容、格式、Lint、类型、测试、构建和 Pages 导出全部通过。
