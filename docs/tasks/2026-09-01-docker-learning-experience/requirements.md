# Docker 学习体验增强

## 已确认目标

1. 丰富各个教程的命令动画细节，优先提升 Docker 动画的阶段信息、对象变化和终端反馈。
2. 完善 Docker 命令终端，让命令输出、对象状态和常见排查路径更接近真实学习过程。
3. 将 Docker 终端迁移到统一的“在线终端”入口，与 Git 终端共享入口但保持各自状态模型。
4. 优化学习路径中的嵌入动画 UI，在课程卡片中保持重点信息、可读性和可操作性。

## 范围

- Docker 教学时间轴、阶段文案、终端输出和 Docker 专属舞台。
- Docker 浏览器内存仿真器、命令建议、对象操作与在线终端入口。
- `CommandAnimation` 的嵌入模式和课程页动画卡片样式。
- 对应单元测试、浏览器验收和工程文档。

## 不包含

- 不连接真实 Docker Engine，不执行宿主机 Shell，不创建公网沙箱。
- 不修改 Docker 课程 Schema 的既有字段约束，不改变课程答案和平台指引语义。
- 不发布远程版本，不修改线上站点。

## 验收标准

- `/terminal/` 可切换 Git 与 Docker，切换后显示对应终端、对象面板和命令提示，刷新前各模式操作互不串状态。
- Docker 高频命令能显示更完整的可观察输出，关键对象操作后资源面板和诊断信息同步变化，错误仍保留原状态。
- Docker 动画的输入、执行、过渡、完成阶段能展示对象/网络/卷/端口/镜像层等具体变化，而不是只有重复的一行结果。
- `/courses/docker/` 及课程详情中的嵌入动画在桌面和 390px 下不遮挡、不横向穿出，重点信息和控制仍可操作。
- 相关测试、内容校验、TypeScript、Lint、格式检查和生产构建通过。
