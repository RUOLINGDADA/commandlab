# 命令独立 UI 与 VS Code Git 工作区

## 已确认目标

- 每个 Git/Docker 动画命令拥有可识别的专属 UI，不再只复用同一张通用画布。
- Git 工作区需要像 VS Code Source Control 与 Git Graph 一样清晰显示当前分支、HEAD、分支列表、提交历史、暂存区、修改和未跟踪文件。
- 现有内存教学状态机、逐帧时间轴和动画 URL 保持可用。

## 范围

- 新增按工具与命令 slug 注册的专属视图配置和渲染组件。
- Git 命令视图覆盖工作区、暂存、提交、分支切换、合并、变基、恢复、远端和诊断等命令。
- Docker 命令视图按镜像、容器、网络、卷、编排、清理和诊断设计不同对象面板。
- 动画详情页保持静态路由、自动播放、逐步控制和移动端适配。
- 补充可观察 DOM 测试与浏览器验收记录。

## 验收标准

- 页面 DOM 包含命令专属视图标识和专属标题；不同命令呈现不同主布局与对象面板。
- Git 页面显示当前分支、HEAD、分支列表、ahead/behind、Changes、Staged Changes、Untracked 和提交历史。
- branch/switch/merge/rebase 页面分别显示指针创建、HEAD 切换、双父汇合和提交重放路径。
- add/commit/reset/stash/remote 页面分别显示文件入暂存、快照封存、三棵树、抽屉和本地/远端泳道。
- 390px、平板、桌面端不产生整体横向溢出，命令文本和状态信息不重叠。
- 运行内容校验、测试、类型检查、lint、格式检查和生产构建通过。
