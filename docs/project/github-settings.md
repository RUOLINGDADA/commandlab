# GitHub 仓库设置

首次推送后在 `RUOLINGDADA/commandlab` 完成以下设置：

1. 将默认分支设为 `main`。
2. Settings → Pages → Source 选择 GitHub Actions。
3. 为 `main` 建立 Ruleset：禁止删除和强推、要求 Pull Request、要求 `CI / quality` 通过。
4. 合并方式仅启用 Squash merging，并自动删除已合并分支。
5. 启用 Issues、Private vulnerability reporting、Dependabot alerts 和 Secret scanning（账号能力可用时）。

个人仓库只有一名维护者时，不强制第二人批准；仍必须通过自动检查。
